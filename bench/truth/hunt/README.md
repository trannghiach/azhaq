# Known issues per lab, for `azhaq hunt`

One file per lab. Each line is a route (path, or a template with `{param}`), then a TAB, then why a tester looks there first. The issues come from the apps' own documentation and source: Juice Shop's challenge list, VAmPI's README, DVGA's and DVNA's docs, and DVWA's modules.

The bar for `azhaq hunt`: of the listed routes the map holds, at least 90% appear in the top 20 of the hunt list, each with a reason. For DVWA the window is the top 25. Files ending in `-signed-in` are for runs that sign in first. Do not edit these files to make the bar pass.
